# Saphal Russian

A complete Russian course for a Nepali speaker. Every Russian word, sentence and
dialogue is written in Devanagari the way Russians actually say it, with the
stressed syllable marked.

Open it at https://saphalism007.github.io/saphal-russian/

This repository holds only the built app. It is one HTML file that works
offline and can be installed on a phone, plus the dictionary in dict/.

## Dictionary

The files in dict/ are adapted from the OpenRussian.org dataset
(https://github.com/Badestrand/russian-dictionary), shared under the Creative
Commons Attribution ShareAlike 4.0 licence
(https://creativecommons.org/licenses/by-sa/4.0/). They are shared under the
same licence. Changes: only words with an English meaning are kept, stress
marks are written as combining accents, punctuation is normalised, a subset of
forms is kept, and a Devanagari pronunciation is added by this app's rules.
